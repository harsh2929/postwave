# Sending API

For workspaces on the **Sending** tier add-on (BYO sender or Moosewave-provisioned dedicated IP).

## Endpoints

| Method | Path                            | Purpose                                       |
| ------ | ------------------------------- | --------------------------------------------- |
| POST   | `/api/v1/sending/provision`     | Request a new sending domain / IP.            |
| GET    | `/api/v1/sending/state`         | Current provisioning + warmup state.          |
| POST   | `/api/v1/sending/warmup:start`  | Begin the warmup ramp.                        |
| POST   | `/api/v1/sending/warmup:pause`  | Pause warmup (e.g., during reputation event). |
| POST   | `/api/v1/sending/warmup:resume` | Resume.                                       |
| GET    | `/api/v1/sending/warmup/state`  | Current day, daily cap, engagement metrics.   |

## Provision

```bash
curl -X POST https://api.moosewave.com/api/v1/sending/provision \
  -H "Authorization: Bearer $POSTWAVE_KEY" \
  -d '{ "domain": "send.yourdomain.com", "type": "dedicated_ip" }'
```

Response includes the DNS records you need to add (SPF include, DKIM CNAME, MX, return-path). See [account setup](/getting-started/account-setup).
