# OpenAPI 3.1 spec

The full API surface is published as a versioned OpenAPI 3.1 document.

## Spec URL

```
https://docs.moosewave.com/openapi.yaml
```

The spec is regenerated on every API release. SDK auto-generation (TypeScript, Python, Go) is driven from this exact file.

## Browse interactively

The Scalar viewer below is embedded for quick reference:

## Generating clients

With `openapi-generator-cli`:

```bash
openapi-generator-cli generate \
  -i https://docs.moosewave.com/openapi.yaml \
  -g typescript-fetch \
  -o ./postwave-client
```

Or use one of the official SDKs (recommended) — see [API overview → SDKs](/api-reference).
