# Automations API

Manage automations and trigger custom events.

## Endpoints

| Method | Path                                        | Purpose                              |
| ------ | ------------------------------------------- | ------------------------------------ |
| GET    | `/api/v1/automations`                           | List.                                |
| GET    | `/api/v1/automations/{id}`                      | Get one.                             |
| POST   | `/api/v1/automations`                           | Create.                              |
| PATCH  | `/api/v1/automations/{id}`                      | Update.                              |
| POST   | `/api/v1/automations/{id}:pause`                | Pause all in-flight runs.            |
| POST   | `/api/v1/automations/{id}:resume`               | Resume.                              |
| POST   | `/api/v1/automations/{id}:activate`             | Move from `paused`/`draft` to live.  |
| GET    | `/api/v1/automations/{id}/runs`                 | List runs (filterable).              |
| GET    | `/api/v1/automations/{id}/runs/{run_id}`        | Get one run with full step history.  |
| POST   | `/api/v1/events`                                | Emit a custom event (drives `custom_event` triggers). |

## Emit custom event

The most common API call against this surface:

```bash
curl -X POST https://api.moosewave.com/api/v1/events \
  -H "Authorization: Bearer $POSTWAVE_KEY" \
  -d '{
    "subscriber_email": "alice@example.com",
    "event_name": "checkout_completed",
    "payload": { "amount": 149, "product": "Pro Plan" }
  }'
```

Moosewave looks up the subscriber by email, finds all automations with `custom_event` triggers matching the event name + filter, and starts a run for each.

Response:

```json
{
  "event_id": "evt_01HK...",
  "matched_automations": 2,
  "started_runs": ["run_01HK...", "run_01HK..."]
}
```

## Pause / Resume

Pausing freezes all in-flight runs at their current node. Sends scheduled during the pause do **not** retroactively fire on resume.

## Get run

```bash
curl https://api.moosewave.com/api/v1/automations/auto_.../runs/run_01HK... \
  -H "Authorization: Bearer $POSTWAVE_KEY"
```

```json
{
  "id": "run_01HK...",
  "automation_id": "auto_01HK...",
  "subscriber_id": "sub_01HK...",
  "status": "in_progress",
  "current_node_id": "node_3",
  "next_wake_at": "2026-05-02T09:00:00Z",
  "step_history": [
    { "node_id": "node_1", "type": "send_email", "entered_at": "...", "exited_at": "..." },
    { "node_id": "node_2", "type": "wait",       "entered_at": "...", "exited_at": "..." }
  ]
}
```
