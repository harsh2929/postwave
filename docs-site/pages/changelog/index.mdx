# Changelog

This is an archived draft, not release evidence. A shipped release requires an
immutable source commit, signed artifact digests, promotion evidence, a real
release date, and a linked customer-visible change record.

## Unreleased v0.1 candidate

Proposed scope only. None of the bullets below proves public beta, GA, plan
availability, provider certification, or customer entitlement.

- Migration adapters: Mailchimp, ConvertKit, Substack, Beehiiv, MailerLite, CSV.
- Inbox Reality: SPF/DKIM/DMARC/BIMI validation, controlled-inbox observation machinery (live adapter/roster certification still required), AI Diagnostician, Pre-Send Predictor.
- Voice AI: 5 source types, 50 hand-authored templates, fidelity scoring.
- Forms: GrapesJS builder, hosted + embedded modes, double opt-in.
- Automations: 4-node-type runtime (wait, send_email, branch, action), 4 trigger types.
- API v1: full REST surface, OpenAPI 3.1 spec, official SDKs (TypeScript, Python, Go).
- Webhooks: HMAC-SHA256 signing, 12 event types.
- Source and deployment boundaries documented; no supported self-host distribution announced.
