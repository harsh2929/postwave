# The 50-template library

Moosewave ships with **50 hand-authored templates** organised into 11 categories. Each template is a structured *sequence skeleton* — number of emails, send-cadence, per-email purpose, variables — that generation fills in using your [voice profile](/voice-ai/profile).

## How to filter and pick

In **Voice AI → New sequence**, you can filter by:

- **Category** (welcome, re-engagement, product launch, course launch, SaaS onboarding, sales, partnership, community, crisis, newsletter series, misc).
- **Length** (single email, 2–3 emails, 5+ emails, 7+ emails).
- **Audience type** (cold, warm, paid, churned, prospect, customer).

Click any template to see its email-by-email outline before generating.

## How to use one

1. Pick a template.
2. Fill in template variables (your product/newsletter name, the offer, key dates, etc.).
3. Confirm the [voice profile](/voice-ai/profile) to use.
4. Set the [4 sliders](/voice-ai/generation) (formality, length, urgency, personalisation).
5. Click **Generate**. Each email returns with a [fidelity score](/voice-ai/fidelity-scoring); regenerate any below 60.
6. Review and edit each email. Save as an [automation](/automation) and wire to a [trigger](/automation/triggers).

## Total

50 templates — covering ~95% of newsletter operators' needs. If you have a sequence shape that isn't covered, you can author a custom template under **Voice AI → Templates → New** (admin role required).
