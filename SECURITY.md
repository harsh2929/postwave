# Security

Do not include credentials, access tokens, private keys, tenant data, environment
files, or production deployment records in issues or pull requests.

To report a vulnerability privately, use this repository's **Security → Report
a vulnerability** feature. Do not publish working credentials or exploit details
in a public issue. If you discover an exposed credential, its owner should
revoke or rotate it; deleting a file alone does not invalidate a credential.

See [PUBLIC-RELEASE.md](PUBLIC-RELEASE.md) for the source-export boundary and
[LICENSE-BOUNDARY.md](LICENSE-BOUNDARY.md) for the AGPL/MIT/proprietary boundary.
